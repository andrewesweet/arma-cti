### Added

- **Every gate run's wall clock is recorded, and a durable slowdown is said once at the top of an orchestrator's turn (#446).** Between 2026-08-05 and 2026-08-19 the gate roughly doubled and nobody noticed for two weeks: no commit caused it (test count grew 2.43× while the suite's measured work grew 1.23×, a `pytest-xdist` `--dist load` penalty that scales with test count), so no bisect could have stood out — the kind of regression only a standing measurement catches. `just unit` and `just fast` now append one row each to `~/.arma-cti/gate-clock/records.jsonl` — timestamp, recipe, wall seconds (read from `/proc/uptime` at both ends, the kernel's monotonic clock, because `CLOCK_REALTIME` steps under NTP mid-run), exit status, HEAD, collected test count, load average and foreign gate-process count — and `just watch-report` gains a sixth read: one line when the median of the last ten green runs of a recipe exceeds 1.25× its anchor in `tools/gate-clock-anchor.json`. The anchor is the mechanism and moves only by hand, in a diff: a rolling baseline's worst step across the regression window was 1.41× against steady-state noise of 0.85×–1.27×, so it would have normalised to exactly the drift it exists to catch, while the anchor fires on the measured 2026-08-10 shape (1.37×) and stays silent on 08-06 (1.01×) and 08-08 (1.14×) — the derivation, with its day-median table, is `tools/gate_clock.py`'s header. Red runs are recorded with their status but excluded from the comparison (a red suite is faster, and admitting one flatters the median), the report is silent while the Arma tier owns the box, and the fired line carries the window's load-1m median so a busy box can be read off the line itself. Each anchor entry's `set` date bounds the comparison window to green runs on or after it, so an anchor lowered after a measured improvement reads `insufficient_sample` until five new greens exist rather than false-firing against the slower rows still on disk. A missing, unparseable or half-edited anchor file prints one line per recipe rather than reading as an unset anchor — silence there would be the exact failure #446 exists to prevent, reintroduced inside the fix — and `just check`'s new gate-clock anchor leg makes the same finding a red before it can land. `just gate-clock-history` prints each recipe's medians, spans and anchor with its set date, for the retro asking what moving an anchor would be moving from. Recording costs one `uv run` start per recipe (~0.3 s against a ~190 s tier) plus one file write at collection time.
