### Added

- **`just module-cost <module>` reports one test module's serial wall and CPU, with machine
  load and the foreign gate-process count stated (#685).** #447's family — #455, #456,
  #457 — each ask for this figure and the command surface offered no way to take it: `just
  unit` runs the whole tier in parallel, and `gate_clock` records only its whole-tier wall,
  so one module's own serial wall and CPU had no reading anywhere; #457's dispatched
  session could not reach bare `uv run pytest` or `/usr/bin/time`, so the same acceptance
  criterion was satisfiable or not depending on who drew the dispatch. `tools/module_cost.py`
  passes `-n0` itself, overriding pyproject's `-n auto`, and its row states
  `mode=serial` so a contended figure cannot pass for an isolated one; a red module is
  still a measurement, its exit code propagating. The run is bounded at both seams — the
  recipe's `timeout` and the child pytest's own deadline — and a reading that cannot be
  taken, in the load or the foreign count, renders `null`, never a zero standing in for
  unknown. The deadline kill reaches the child's whole process group, so a module whose
  tests spawn holders of their own leaves no descendants alive behind it. The row's load
  and foreign-count readings are read outside the child's lifetime, so the tool never
  counts its own pytest child. The command-table row for `AGENTS.md` and the
  `Bash(just module-cost:*)` permission grant are proposed in #685's close: the first is a
  human sign-off gate, the second an allowlist change on `.claude/settings.json`, a
  routing class 6 gate path barred to dispatched authors.
