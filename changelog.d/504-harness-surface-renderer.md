### Added

- Add a versioned harness-bundle renderer whose target capabilities are derived from implemented target adapter methods: Claude Code implements hooks and project instructions, while Codex implements project instructions and has no hooks destination.
- Refuse a live dispatch identity on caller-selected rendering and promotion as a floor against accident and shortcut, never containment: a same-user in-process caller can strip `CTI_DISPATCH_ID`, rebind the module's names, or write destination bytes directly, and no in-process guard prevents that. Rendering into a renderer-owned temporary layout stays available during dispatch. Promotion checks current effective directory and file access and rejects non-file outputs, but cannot prove that filesystem access will remain unchanged between its preflight and writes. Enforced controls are out of process: `just check` refuses a gated-path change on every lane regardless of how the write happened (#500), and a dispatched session cannot write under `.claude/` (#294).
- Compare generated paths, file bytes, and file modes deterministically, while explicitly excluding mtimes and created-directory modes. Expose render, check, and promote through `just` recipes.
