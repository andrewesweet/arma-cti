#### Fixed

- The stage recorder no longer over-counts three ways (#552, from `fable-max`'s terminal review of #490). A dispatched non-pipeline seat running `just review exchange` records no `exchange` stage arrival, the same `STAGE_OF_SEAT` filter the gate and land seams already carry. A hand landing whose `just land` exited 2 and was re-run records one `land` arrival rather than two: the re-run carries no dispatch id for the recorder's dispatch deduplication to key on, so the land seam is now idempotent over an arrival already journalled for the same issue and stage — an inflated land count was deflating land's first-pass yield, and rolled yield multiplies. The observatory's hazards list now states that one unreadable dispatch record anywhere makes every absent-journal issue's first arrival record `undetermined` whichever issue the record names — global, single-firing per issue, and accepted as the safe direction — so a spike in `stage_arrivals_undetermined` can be damage to one unrelated record rather than a finding about the issues it appears on.
