#### Added

- The attribute registry (`tools/attribute_registry.py`): one home for every `cti.*` and `gen_ai.*` name the project emits, reads or renders as a scope, each row carrying its kind, requirement level and a one-line reason. A new `just check` leg (`check-attributes`) derives every name the working tree's Python carries — tracked and uncommitted files, tokenised, in three forms: whole strings, `key=value` renderings, and f-string prefixes — and reds on a name the registry does not carry (#484).
- Wait causes are now recorded. A dispatch, queue-decision or review exchange that is blocked emits one `cti.wait.blocked` event carrying `cti.wait.block_reason` from a closed nine-value vocabulary stated once in the registry module, alongside `cti.wait.surface` and, where a refusal was the evidence, `cti.wait.refusal`. A cause that cannot be determined is recorded as `undetermined` — a queue that stops with candidates standing on heterogeneous drops, or a breaker trip on a failure class the mapping does not name — never omitted and never guessed. Emission rides the existing `tools/otel_event.py` seam, stays fail-open, and journals each event with its export outcome beside the surface's own state; a collector that refuses leaves the caller's exit status unchanged. The vocabulary's `slot_unavailable` value is registered for the regression tier's no-slot stop, whose bash seam does not yet emit — the queue (`waiting_human`, `wip_limit`, `undetermined`), dispatch (`lane_peak_band`, `quota_exhausted`, `breaker_open`, `worktree_occupied`, `undetermined`) and review-exchange (`waiting_reviewer`) surfaces are the first emitters.
